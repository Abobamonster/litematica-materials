# Установка

1. Распакуйте kit и откройте **Index.html** в Chrome или Edge.
2. Создайте проект на https://script.google.com/ и вставьте **Code.gs** в файл кода.
3. Нажмите **Развернуть → Новое развертывание → Веб-приложение**. Выполнять **от вашего имени**, доступ **«Только я»**. Подтвердите разрешения.
4. Скопируйте ссылку **…/exec** в **«Google · настройка»** приложения.
5. Загрузите схему → **Создать Google Таблицу** → подтвердите в новой вкладке и дождитесь ссылки на таблицу.

**Обновление:** замените Code.gs → **Развернуть → Управление развертываниями → карандаш → Новая версия → Развернуть**. Закройте старые вкладки создания и заново откройте приложение.

HTML-файл в Apps Script для экспорта не нужен. Если хотите работать прямо в Apps Script: **+ → HTML**, имя **Index** без расширения, вставьте новый `Index.html` и разверните новую версию.
